# 本地人餐厅推荐研究规则

## 目标与边界

餐厅研究的目标不是收集网红榜单，而是找到当地人反复提及、目前仍营业、与当天路线真正顺路的具体门店。抖音、小红书等内容平台用于发现候选和观察评论，地图、商户官方账号、电话或订座页面用于确认门店、营业状态与路线。平台 IP 属地只是一项线索，不能单独证明用户身份，也不能据此声称某条评论一定来自“真正本地人”。

评论研究只用于内部判断。客户文档不展示评论用户名、头像、账号主页、IP 截图、评论截图或可识别个人的信息，也不把研究过程写进正文。

## 研究顺序

1. 先按每日路线确定用餐窗口：上一站、下一站、可接受步行/打车范围、预计用餐时间、人数、忌口和预算。
2. 在抖音、小红书等平台组合搜索：`城市 + 本地人推荐 + 片区/景点/菜系`、`城市 + 本地人常去 + 店名`、`片区 + 老店/早餐/夜宵`。优先看多个独立发布者与不同时间的内容，不依赖单一探店视频。
3. 阅读评论区，优先记录与目的地对应的省级 IP 属地评论。例如长沙优先湖南 IP；直辖市优先同名直辖市；跨省景区或边界城市可把相邻地区作为补充证据，但必须单独标注。
4. 从有实质内容的评论中提取店名、分店、菜品和使用场景。实质内容包括具体分店、常点菜、营业时段、排队规律、口味变化、`从小吃/经常去/附近上班`等可核查细节。只写“好吃”“必吃”“冲”不算有效证据。
5. 候选店原则上需在至少 2 个相互独立的帖子或账号下出现，并获得至少 3 条有实质内容的同属地评论支持。证据较少时，最低为 2 个独立帖子各有 1 条实质评论；此时只能作为普通候选，不能对客户宣称“本地人都推荐”。
6. 再用地图和可靠商户信息核验准确分店、当前营业状态、营业时间、休息日、预约方式、与路线的实际距离和交通时间。门店存在与营业时间以地图、官方商户页或当天电话确认优先，平台热度不能代替核验。
7. 将通过核验的候选放回每日动线，按顺路程度、餐别匹配、当地特色、证据质量、忌口与预算排序。

## 广告与失真排除

出现以下信号时提高广告风险；多个信号同时出现时直接淘汰或只留作待核验线索：

- 发布内容明确为团购、商业合作、到店置换或只围绕优惠券
- 评论文案重复、口号化、集中在短时间出现，或多账号复制相同句式
- 评论者主页长期只推广餐厅、附联系方式、暗号、返现或导流信息
- 只有创作者、商家账号或疑似员工自荐，没有独立顾客的具体体验
- 评论只说“天花板、闭眼冲、必吃”，没有分店、菜品或真实使用细节
- 地图显示长期歇业、地址对不上、近期大量反映换店名/换老板/品质显著下降

不得因为 IP 属地相符就忽略广告信号，也不得把一次孤立评论包装成共识。

## 路线匹配与正文写法

- 每个主要用餐窗口通常给 2—4 个具体选择；远郊、景区内或可靠候选较少时 1—3 个即可
- 优先选择从上一站或下一站步行约 10—15 分钟内，或短途接驳可到的门店。除非它是用户明确想吃的特色餐或当日核心体验，不为吃饭增加超过约 15 分钟的单程绕行
- 必须写准确分店或能唯一定位的地标，避免同名店和错误分店；菜品只写评论中反复出现且当前菜单可确认的 1—3 项，不凭印象编造
- 同城案例中的原餐厅也要重新走完营业与路线核验；若仍顺路可保留原句和顺序，失效、绕路或证据明显不足时只替换相应店名
- 客户正文保持简短，例如：`午餐推荐：店名（具体分店）、店名（具体分店）`；需要时补一句顺路位置、适合餐别或代表菜，不展示“湖南 IP 评论数”等内部证据
- 研究后仍没有可靠候选时，优先把用餐窗口移动到当天最近的已核验餐饮聚集区；只有确实无法核验时才写“暂无可靠具体推荐”，不得虚构店名，也不要大量使用“附近解决”

## 内部证据表

每次完整攻略为最终入选或淘汰的餐厅保留简短内部记录，至少包含：

| 字段 | 内容 |
|---|---|
| 用餐窗口 | 日期、餐别、上一站与下一站 |
| 搜索记录 | 平台、关键词、帖子/视频日期 |
| 评论证据 | 匹配属地、有效评论数量、具体内容摘要，不记录用户名 |
| 广告风险 | 低/中/高及判断理由 |
| 地图核验 | 准确分店、营业状态、时间、休息日、预约信息 |
| 路线核验 | 与前后景点距离、预计步行/接驳时间、是否绕路 |
| 结论 | 入选、备选或淘汰及原因 |

动态信息无法访问或平台评论区不可读取时，应如实标记证据不足，转用可访问的独立本地讨论、地图近期评价和官方营业信息交叉核验；不能假装已经抓取评论。

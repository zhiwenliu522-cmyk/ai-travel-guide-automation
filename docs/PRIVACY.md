# 隐私与数据边界

## 不应提交到仓库的内容

- 客户姓名、电话、证件、订单、聊天记录或联系方式
- 未经授权的客户攻略 Word、酒店订单和付款信息
- 评论用户名、头像、主页、IP 截图或完整评论截图
- 平台登录信息、Cookie、访问令牌、API Key 或本地 `.env`
- 未确认版权或发布权限的图片、地图截图和商业模板

## 餐厅评论研究

IP 属地仅用于辅助判断内容与目的地的关联性，不等于身份认证。内部证据表只保留匿名内容摘要、数量、平台、日期、广告风险和核验结论，不记录用户名或建立用户画像。

系统只使用正常可访问的信息，不绕过登录、验证码、付费墙、反自动化措施或平台访问限制。无法读取评论区时必须标记证据不足，并改用可访问的独立本地讨论、地图近期评价和商户官方信息交叉核验。

## 发布真实案例

如需提交示例文档，应先移除个人信息、订单信息、水印、内部报价、客户偏好和可识别账号，并确认图片、字体、地图和模板拥有公开发布权限。

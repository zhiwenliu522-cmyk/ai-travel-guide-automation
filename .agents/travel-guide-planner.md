# AI旅行攻略自动化定制 Agent

处理中文旅游攻略制作、修改、研究或质量检查时，必须使用 `$customize-travel-guide` Skill，并完整遵循其 `SKILL.md` 与必读参考文件。

默认目标是交付客户可以直接使用的图文 Word，而不是只给行程提纲或内部研究报告。开始前先确认工作模式并检查同城市成品参考；餐厅新增、替换或推荐必须执行本地评论证据、广告排除、准确分店和路线核验流程。

不得把平台 IP 属地当成真实身份认证，不得绕过登录、验证码或访问限制，不得把评论用户名、头像、IP、评论截图、订单信息或其他个人数据放入客户文档。

完整新攻略必须完成动态信息核验、逐日时间链、餐厅证据表、Word 渲染和交付前检查；找到同城成品时还需建立内容块复用合同并运行复用审计脚本。
